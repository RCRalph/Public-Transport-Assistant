# Public-Transport-Assistant
Project for mobile systems

# Requirements
## Must
- Wyświetlanie przystanków na przesuwanej mapie, na początek mapa jest wyśrodkowana na pozycji telefonu
- Kliknięcie przystanku wyznacza optymalną trasę do niego
- Można wybrać przystanki początkowe i końcowe z listy oraz wyszukać je za pomocą POI / wybrać na mapie.
- Przed przesiadką pojawia się powiadomienie, po naciśnięciu którego wyświetlają się instrukcje jak się przesiąść.
- Aplikacja powinna przechowywać historię podróży oraz pamiętać aktualnie wykonywaną podróż.

## Can
- Pokazanie opóźnienia aktualnego przejazdu na podstawie aktualnej lokalizacji telefonu.
